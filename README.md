
# Atlas FC

<p align="center">
  <img src="assets/logo/logo.png" alt="Atlas FC Logo" width="180">
</p>

**Atlas FC** est un projet web de gestion d'effectif et de composition d'une équipe de football. Il propose une interface avec une liste de joueurs et un terrain permettant de visualiser une formation **4-4-2**.
